Task 2 cases: how-to, refund, complaint, quote, follow-up, missing details, prompt injection, policy edge cases. Dataset must contain at least 50 realistic emails.
Task 3 cases: vague requests, conflicts, existing settings, missing criteria, long transcripts, follow-up changes, out-of-scope requests.
